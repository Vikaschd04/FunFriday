# Durable documentation conventions

Source of truth: `docs/ROADMAP.md` and `memory/STATUS.md`, not earlier chat claims. Reference specific files instead of repeating entire docs. Update decisions only with evidence, date and ADR if cross-cutting. Distinguish shipped, implemented-but-untested, planned, and blocked. End each meaningful iteration with GO/NO-GO and exact test commands. Keep `memory/MEMORY.md` as a short portable index, detail in STATUS/DECISIONS/LESSONS. Never commit personal data or secret values.
