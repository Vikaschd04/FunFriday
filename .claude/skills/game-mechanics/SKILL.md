# Multiplayer game mechanic policy

Source: `docs/GAMES.md`, `docs/CONTENT_POLICY.md`. Favor simultaneous activity and genuine teammate conversations. A game spec must include player ranges, team and audience modes, state machine, config schema, round deadlines, server-only secrets, action validation, scoring/noncompetition, consent, host controls, failure and rejoin states. 15-20 is the default; large groups get parallel/teams rather than serial turns. No copied proprietary content, sensitive personal probing or monitoring. Unit-test transitions deterministically with controlled time and random seed.
