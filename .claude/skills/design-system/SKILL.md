# FunFriday product design conventions

Source: `docs/DESIGN_SYSTEM.md`. Brand: ink #202949, violet #7765EF, coral #FF7067, mint #35C8B2, sun #FFD166, light canvas #F8FAFC. Tokens are candidates: check actual contrast before using text. A premium playful corporate app, not childish or generic dashboard UI. Build strong typography, consistent 8px rhythm, beautiful game previews, short purposeful motion (180-240ms entry, 300-500ms reveals), subtle success/celebration and accessibility fallback. Design every empty, loading, error, paused and offline state. Keyboard, visible focus, mobile 320px and `prefers-reduced-motion` are non-negotiable. Motion must communicate state, not distract.
